# SAR Paternoster

Moderne Warenausgabesystem mit futuristischem Dark Mode UI.

## 🚀 Start

1. **Repository klonen:**
   ```bash
   git clone https://github.com/lumsen/sar-paternoster.git
   cd sar-paternoster
   ```

2. **Entwicklungsmodus:**
   ```bash
   npm start          # Entwicklungs-Server starten (Port 3000)
   # Oder direkt: src/index.html im Browser öffnen
   ```

3. **Deployment zu GitHub Pages:**
   - Push zu `main` → automatisch deployt
   - Live: `https://lumsen.github.io/sar-paternoster`

## 📁 Features

- 🔍 Barcode-Scanner Integration
- 📊 Artikelmanagement mit Dark Mode UI
- 🚀 Automatisches GitHub Pages Deployment
- ✨ Glassmorphism Effekte & Neon-Glow

## 🔧 Pages

- **`/`** - Startseite mit Interface-Auswahl
- **`pages/ausgabe.html`** - Dispensation Interface
- **`pages/admin.html`** - Administration Panel
